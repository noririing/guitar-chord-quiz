# ギターコード構成音チェック

ギターコードの構成音を覚えるための、シンプルなクイズサイトです。

**サイト:** https://noririing.github.io/guitar-chord-quiz/

## 使い方

1. ランダムにルート音（C / D / E / F / G / A / B）が出題されます。
2. 「答えを見る」を押すと、メジャーとマイナーの構成音が表示されます。
3. もう一度押すと次の問題に進みます。

スペースキー / Enter キーでも操作できます。

## 出題方法

7つのルート音を1セットとしてシャッフルし、出し切ったら再シャッフルする「シャッフルバッグ方式」です。
7問ごとに全ルートが1回ずつ出題されるため、ランダムでありながら出題回数に偏りが出ません。
また、同じ問題が2回続けて出ることはありません。

## 収録コード

| ルート | メジャー | マイナー |
|---|---|---|
| C | C E G | C E♭ G |
| D | D F♯ A | D F A |
| E | E G♯ B | E G B |
| F | F A C | F A♭ C |
| G | G B D | G B♭ D |
| A | A C♯ E | A C E |
| B | B D♯ F♯ | B D F♯ |

## 構成

`index.html` 1ファイルのみ（HTML + CSS + JavaScript）。ビルド不要で、ブラウザで直接開けば動きます。
